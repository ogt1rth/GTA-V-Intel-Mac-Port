# GTA-V on Mac

The current Mac instructions are maintained in the [README](../README.md) and the [Intel build guide](BUILD_INTEL.md). This fork targets Macs and requires your own compatible game files; it does not distribute those files.

The app is named **GTA-V**. Build it locally, open it, select your game folder, and use keyboard/mouse or a controller. Settings opens with Command-comma; Escape closes settings and mod-menu screens.

Local saves, mods and diagnostics remain under `~/Library/Containers/io.github.playgta5ios.app/Data/Documents`. Logs are stored locally; there is no Send Log workflow in this fork.
